# 🚦 E-Commerce-Retouren-Ampel

Ein Machine-Learning-Projekt zur Vorhersage von Retourenwahrscheinlichkeiten im Online-Handel.

## 📝 Projektbeschreibung
Dieses Projekt nutzt historische Transaktionsdaten, um ein Vorhersagemodell zu trainieren, das das Risiko einer Warenrücksendung bewertet. Das Ergebnis wird als intuitives **Ampelsystem (Grün/Gelb/Rot)** dargestellt, um Händlern und Kunden eine Entscheidungshilfe zu bieten.

## 🚀 Status: Q-Phase
Aktuell befindet sich das Projekt in der **Q-Phase (Questioning)** des QUA3CK-Modells. 
- Das Konzept und die Forschungsfragen sind im Notebook `Q-Phase.ipynb` dokumentiert.
- Die Recherche nach geeigneten (deutschen) Datensätzen läuft.

## 🛠️ Tech-Stack
- **Python** (Datenverarbeitung)
- **Jupyter Notebook** (Konzeption & Analyse)
- **Streamlit** (Geplante Web-App)
